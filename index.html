Curriculum

Four sessions.
One transformation.

Each session builds on the last — from understanding AI, to using it for itineraries, to mastering Claude as a full business system.

01
Session One

AI Literacy &
Prompt Engineering

The team already uses free ChatGPT and Claude. This session doesn't start from zero — it resets how they think about AI and gives them a structured method to get dramatically better outputs, every single time.

Part A
AI Literacy
  • Why free-tier usage gives inconsistent results, and what actually changes with better usage
  • ChatGPT vs Claude vs Gemini: which tool wins for which travel task
  • The shift from "asking AI" to "briefing AI like a junior consultant"
  • Data privacy basics: what to share and what should never go in
  • Understanding hallucinations: catching wrong information before it reaches a client
Part B
Prompt Engineering with the CRAFT Framework
  • Why inconsistent outputs are a prompting problem, not a tool problem
  • The CRAFT Framework applied to travel: Curate, Refine, Audience, Feedback, Track
  • How to brief AI using client context from their SOP intake form
  • Role-based prompting for luxury travel consultants
  • Chained prompting: building itineraries one step at a time
  • Building reusable prompt templates for honeymoon, family, anniversary, multigenerational trips
✦
Hands-On Activity
Each consultant takes a real or mock client brief from the SOP form and builds a complete Day 1 itinerary draft using CRAFT. They leave with at least two saved prompt templates ready to use the next morning.
02
Session Two

Building Itineraries
with AI

The biggest time sinks are building itineraries from scratch and polishing raw supplier content. This session solves both — and standardises quality across the entire team.

What Will Be Covered
From Supplier Content to Client-Ready Proposals
  • Taking raw supplier content and rewriting it to sound like Hansa, not a brochure
  • Structuring day-by-day itineraries so they read beautifully, not like copied spreadsheets
  • Adding sensory language and emotional resonance to destination descriptions
  • Maintaining consistency: getting every consultant to produce the same quality of writing
  • Building destination description banks for Hansa's top destinations (Italy, Greece, Norway, Jordan, Scandinavia)
  • Adapting one base itinerary for multiple client profiles instantly: honeymoon, family, multigenerational
  • Using AI to cross-check itinerary routing, pacing, and logical gaps before client delivery
✦
Hands-On Activity
Each consultant takes an actual supplier-provided itinerary, pastes it into AI, and transforms it into a polished Hansa-quality document. They also build one destination description for a city they frequently sell — saved and ready to reuse.
03
Session Three

Claude Mastery
for Hansa

This is where Claude stops being a chat tool and becomes a proper business system for the team — including connecting Canva for end-to-end proposal design.

Part A
Understanding Claude's Ecosystem
  • Claude vs ChatGPT: why Claude is built for delegation and long-form work
  • The three Claude models: Haiku, Sonnet, Opus — which to use for which task
  • Claude Pro vs free version: what actually unlocks for a client-facing team
Part B
Claude's Core Features for Hansa
  • Projects: creating a dedicated Hansa project with client context, destination knowledge, and tone built in
  • Memory and Personal Preferences: teaching Claude about Hansa's style and SOP so every prompt starts right
  • Artifacts: generating formatted documents, itinerary layouts, and proposals directly in chat
  • Document Upload: uploading supplier PDFs and asking Claude to rewrite them in client-ready language
  • Deep Research: pulling accurate destination, visa, and hotel information without manual browsing
  • Extended Thinking Mode: for complex multi-country itineraries with tight routing and logistics
Part C
Connectors and Canva Integration
  • What Connectors are: how Claude connects to external tools and acts on real data
  • Step-by-step live setup of the Canva connector inside Claude
  • Using Claude and Canva together: Claude generates content, Canva renders the designed proposal
  • Building a repeatable Hansa proposal template: cover, day-by-day, hotel highlights, pricing summary
  • Duplicating and adapting one template for different destinations quickly
  • Saving the entire workflow so any consultant can run it — not just the most experienced one
✦
Hands-On Activity
Each consultant connects Canva to their Claude account, takes the itinerary built in Session 2, and produces a finished designed proposal document. They leave with a working system they can use on a real client the very next day.
04
Session Four

Client Communication
& Social Media with AI

Covering two remaining areas: making every client touchpoint faster and more consistent, and giving Hansa a realistic path to owning their social media without relying on short-term external partners.

Part A
Client Communication
  • Writing faster, warmer inquiry response emails while keeping the personal Hansa tone
  • Using AI to summarise a client call into a structured brief so nothing is lost
  • Drafting WhatsApp and email follow-ups that do not feel copy-pasted
  • Handling common client objections in writing: pricing pushback, comparison shopping, delayed decisions
  • Building a template library: inquiry acknowledgment, itinerary delivery, payment reminder, post-trip thank you
Part B
Social Media Content with AI
  • Using AI to generate Instagram captions, destination posts, and travel inspiration content
  • Repurposing client testimonials into social-ready content
  • Using Canva AI to design destination posts without needing a dedicated designer
  • Building a 30-day Instagram content calendar using AI
  • What content strategy works for a boutique luxury referral-driven brand
✦
Hands-On Activity
Each consultant creates 3 ready-to-post Instagram captions and one designed destination post for a city they frequently sell.
